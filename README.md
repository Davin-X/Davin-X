## [VistoGallery](https://github.com/Davin-X/visto-gallery) · macOS · Rust + Tauri + React

A fast, private photo and video gallery for macOS. It catalogs the folders you already have, never uploads anything, and handles libraries in the tens of thousands.

- Rust backend: SQLite catalog (sqlx), incremental scans that survive moves and renames, SHA-256 duplicate detection, bundled ffmpeg for MKV/HEVC playback
- React 19 + TypeScript frontend: virtualized grid and timeline, viewer, non-destructive editor, Smart Albums
- Shipped with CI, CodeQL, Dependabot, signed tags and build-provenance attestations

## [MergeFolders](https://github.com/Davin-X/mergefolders) · macOS · Swift + Bash

A Finder extension and CLI that move several folders into one. Matching names become `name (2).ext` instead of overwriting anything, and Preview shows every move before it happens. [Illustrated guide](https://davin-x.github.io/mergefolders/).

- Finder Sync extension and command-line tool share one Bash script; nested folders merge by relative path
- Preview/dry run, destination-scoped lock against concurrent merges, and metadata-preserving cross-volume moves
- MIT licensed, built from source, with shell tests, CI build/signature checks and a GitHub Pages guide

[Source](https://github.com/Davin-X/mergefolders) · [Guide](https://davin-x.github.io/mergefolders/)
